# Superstore Sales & Profit Analysis Dashboard

## Project Overview
This Power BI project analyzes Superstore sales, profitability, customer segments, and discount impact from 2014–2017.

## Objectives
- Analyze sales and profit performance
- Identify loss-making sub-categories
- Understand discount impact on profitability
- Generate business insights and recommendations

## Dashboard Pages

### Page 1 – Executive Overview
- Total Sales
- Profit Analysis
- Regional Performance
- Category Analysis

### Page 2 – Sub-Category Profitability Analysis
- Profit margin analysis
- Loss-making sub-categories
- Regional profitability insights

### Page 3 – Customer & Discount Analysis
- Segment profitability
- Discount vs Profit relationship
- Pricing inefficiency analysis

## Tools Used
- Power BI
- DAX
- Data Visualization
- Business Analysis

## Key Insights
- High sales do not always result in high profitability
- Excessive discounting impacts profit margins
- Tables and Bookcases show weak profitability
- Technology products maintain healthier margins
